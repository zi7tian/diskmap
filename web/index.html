DiskMap磁盘地图

看看磁盘空间都去哪儿了

每个方框代表一个文件或文件夹，面积就是它占用的空间；文件夹里套着它的子文件夹和文件。 颜色表示重要程度——红色是正在运行的程序正在使用的文件，紫色是系统核心，绿色通常可以放心清理。

Every box is a file or folder, and its area is the space it takes up; folders contain their subfolders and files. Colors show importance: red is in use by a running program, purple is the system core, and green is usually safe to clean up.

      DiskMap provides an MCP server (the tool protocol used by Claude, Cursor and other AI assistants). Once connected, the AI can read the scan results, the importance of every item and whether it can be deleted, see what you are viewing and have selected in this window, and point out the files it talks about right here. Everything is read-only; no file is ever deleted or changed.
